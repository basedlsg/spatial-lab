# Experiment Results

This directory contains outputs from Spatial Lab experiments.

## File Naming Convention

```
{experiment_type}_{YYYYMMDD}_{HHMMSS}_{content_type}.{format}
```

Example: `calibration_20251127_103727_results.json`

## File Types

| Suffix | Description |
|--------|-------------|
| `_results.json` | Raw trial data (all individual trial results) |
| `_metrics.json` | Computed aggregate metrics |
| `_analysis.json` | Statistical test results |
| `_summary.json` | Human-readable summary |

## Result Files

### Calibration Experiment Results

- **`calibration_*_results.json`**: Raw trial data
  - 144 trials × 18 fields per trial
  - Includes: trial_id, complexity, prompt_condition, confidence, accuracy, etc.

- **`calibration_*_metrics.json`**: Computed metrics
  - Expected Calibration Error (ECE)
  - Brier Score
  - Overconfidence Rate
  - Breakdowns by complexity and prompt condition

- **`calibration_*_analysis.json`**: Statistical analysis
  - t-tests for calibration significance
  - ANOVA for complexity/prompt effects
  - Correlation analyses

### Scientific Reports

- **`SCIENTIFIC_REPORT.md`**: Human-readable analysis
  - Research question and hypotheses
  - Methods and experimental design
  - Results with tables and statistics
  - Discussion and conclusions

## Metrics Glossary

| Metric | Description | Range | Better |
|--------|-------------|-------|--------|
| ECE | Expected Calibration Error | 0-1 | Lower |
| Brier Score | Mean squared prediction error | 0-1 | Lower |
| Overconfidence Rate | % of high-confidence failures | 0-1 | Lower |
| Accuracy | % of correct spatial decisions | 0-1 | Higher |

## Reproducing Results

To reproduce an experiment:

```bash
cd /path/to/spatial-lab
PYTHONPATH=. python scripts/calibration_experiment.py
```

Results will be saved with a new timestamp.

## Data Schema

### Trial Result Fields

```json
{
  "trial_id": 1,
  "complexity": "simple|moderate|complex|very_complex",
  "prompt_condition": "standard|uncertainty_aware|self_critique",
  "distance_category": "short|medium|long",
  "robot_position": [x, y, z],
  "target_position": [x, y],
  "obstacles": [...],
  "action": "move_to|wait|...",
  "destination": [x, y],
  "confidence": 0.0-1.0,
  "reasoning": "LLM reasoning text",
  "spatial_accuracy": true|false,
  "destination_error": float,
  "latency_ms": int,
  "timestamp": "ISO-8601"
}
```

## Notes

- Large JSON files (>100KB) are gitignored to keep repository size manageable
- `SCIENTIFIC_REPORT.md` is committed as the primary research artifact
- Raw data can be regenerated by re-running experiments
